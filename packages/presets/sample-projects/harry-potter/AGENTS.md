# 哈利波特世界观项目

> 此文件是本项目的目录索引，供创作者和 AI agent 阅读。

## 项目简介

这是一个以「哈利波特」为主题的魔法世界观创作示例项目。在这里你可以扩展霍格沃茨的设定、补充魔法生物、设计新的巫师角色与冒险故事。

## 目录结构

- `world-overview.md` — 世界观总览，记录魔法世界的基础设定。
- `.spherse/` — 项目元数据目录。
  - `project.yaml` — 项目配置（名称、模型等）。
  - `agents/` — AI agent 配置，每个子目录对应一个助手。
    - `worldbuilding-hp-abc123/` — 霍格沃茨世界观助手。

## 使用建议

1. 与「霍格沃茨世界观助手」对话，让它帮你扩展设定。
2. 将新的角色、地点、事件文档保存在项目根目录下。
3. 定期回顾 `world-overview.md`，保持设定的一致性。
